# Vaibhav Sahu — Portfolio

3D performance-marketing portfolio with a Three.js floating-physics hero scene.

## Files
- `index.html` — page markup + styles
- `scene.js` — Three.js 3D background
- `tweaks-panel.jsx` — Tweaks UI primitives
- `app.jsx` — palette + motion controls

## Deploy to GitHub Pages
1. Create a new repo (e.g. `vaibhav-portfolio`)
2. Upload all 4 files (plus this README) to the root
3. Repo → **Settings → Pages**
4. Source: `main` branch, `/ (root)` → **Save**
5. Live at `https://<username>.github.io/vaibhav-portfolio/`

## Local preview
Just double-click `index.html` — keep all files in the same folder.
